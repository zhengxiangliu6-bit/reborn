# 家族重启日记软件说明书

软件名称：家族重启日记  
软件版本：V1.0.0  
申请范围：`douyin` 目录中的抖音小游戏版本

## 一、软件概述

家族重启日记是一款以年度选择为主要交互的生活模拟小游戏。用户创建角色后，从出生开始经历不同人生阶段。每个年度可从随机出现的选择中决定角色行动；不同选择改变健康、智力、魅力、财富、心情等属性，并影响后续升学、职业、家庭与资产。角色离世时，若有子女，可以选择其中一位继承家族继续游玩。

软件采用 JavaScript 编写，运行于抖音小游戏环境。界面使用平台 Canvas 2D API 绘制，触摸事件通过平台接口处理。用户存档使用平台本地同步存储接口。正式发布前仍须使用开发者工具和真机验证。

## 二、运行环境与启动

运行环境为支持抖音小游戏的客户端或抖音开发者工具。项目入口是 `douyin/game.js`，项目配置文件是 `douyin/project.config.json`，游戏配置文件是 `douyin/game.json`。开发者在项目配置中填入对应小游戏 AppID 后，将 `douyin` 目录作为小游戏工程导入开发者工具并编译。

启动后，系统创建游戏画布、读取本地存档并显示标题界面。首次游玩点击“开启新的人生”；已有存档可点击“继续上次的人生”。

## 三、创建角色

用户可从预设姓名中选择角色名称，切换性别并选择家庭出身。出身影响角色的初始现金及部分属性。确认后进入婴幼儿阶段，系统生成当年的选择并保存初始进度。

## 四、年度选择与角色属性

主界面显示角色姓名、年龄、人生阶段、现金与五项属性。每一年系统准备三项可选行动。用户点击其中一项后，系统计算该行动的属性和金钱变化，结算家庭支出、资产维护与自然衰减，再进入下一年。用户也可选择“休息一年”直接推进年度。

随机生活事件按角色年龄和状态筛选。某些事件改变现金或属性，相关经过显示在当前提示和人生记录中。角色健康归零或达到寿命结算条件时，本代人生结束。

## 五、教育与职业

角色在对应年龄进入幼儿园、小学、初中、高中和大学等阶段。幼儿园阶段可选择教育方式；高中结束后系统根据智力和随机因素生成高考分数，用户选择满足分数条件的学校及专业。大学毕业时可选择职业规划，后续可决定是否继续攻读硕士或博士。进入工作阶段后，职业产生年度收入，工作等级可能随属性与年度结算提高。

## 六、商品、活动与家庭

成年角色可进入商城购买符合现金与前置条件的商品或资产。资产可产生年度收益，也可能产生维护支出或在使用年限届满后退出。成年角色每年可参加一次活动，活动结果根据内容表的权重抽取。

角色达到相亲年龄后可追求游戏内人物。满足好感、经济与人物条件时可以结婚；满足家庭条件后可以生育。配偶收入和家庭支出参与年度结算。角色离世后，若有子女，用户可以选择下一代，继承约定比例的现金和家族资产继续游玩。

## 七、存档与续玩

游戏规则引擎位于 `douyin/engine.js`，状态保存为可序列化数据。每次年度准备、关键选择、购物、活动、家庭事件及人生结束时，系统通过 `tt.setStorageSync` 保存状态；下次启动通过 `tt.getStorageSync` 读取并恢复。存档带有版本号，本地缓存被系统清理后可能无法恢复，因此本版本不承诺跨设备同步。

## 八、界面及内容模块

- `douyin/game.js`：创建存储适配、规则引擎和画布界面，启动游戏。
- `douyin/engine.js`：状态、年度推进、条件校验、经济、教育、婚育及继承规则。
- `douyin/ui.js`：像素风格画布绘制、滚动和触摸交互。
- `douyin/content.js`：出身、人生阶段、剧情事件、职业、学校、商品及活动数据。
- `douyin/ads.js`：预留激励视频适配；广告位 ID 为空时不展示广告。
- `douyin/icon.png`：项目内程序绘制的像素图标。
